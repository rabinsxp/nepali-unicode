# 🇳🇵 Nepali Unicode Converter

A **modern, beautiful, and responsive** web application for converting Romanized Nepali text to Unicode Nepali script. Built with React, TypeScript, Vite, and TailwindCSS 4.1.

![Nepali Unicode Converter](https://img.shields.io/badge/Nepali-Unicode-blue?style=for-the-badge&logo=react)

## ✨ Features

### 🎯 **Dual Conversion Modes**

- **Simple Mode**: Flexible, phonetic typing (e.g., both "nam" and "naam" → नाम)
- **Traditional Mode**: Precise, academic conversion (e.g., "naam" → नाम, "nam" → नम्)

### 🎨 **Beautiful Modern UI**

- **Glassmorphism Design**: Beautiful glass-like effects with backdrop blur
- **Gradient Animations**: Smooth, eye-catching color transitions
- **Dark/Light Themes**: Seamless theme switching with system preference detection
- **Responsive Layout**: Perfect on mobile, tablet, and desktop
- **Micro-interactions**: Subtle hover effects and animations

### ⚡ **Performance & UX**

- **Real-time Conversion**: Instant results as you type
- **Zero Latency**: Client-side processing for maximum speed
- **Accessibility**: Full keyboard navigation and screen reader support
- **Progressive Enhancement**: Works without JavaScript (basic functionality)

### 🔧 **Technical Excellence**

- **TypeScript**: Full type safety and IntelliSense
- **Modern React**: Hooks, functional components, and optimized rendering
- **Vite**: Lightning-fast development and build times
- **TailwindCSS 4.1**: Latest utility-first CSS framework

## 🛠️ Development

### Prerequisites

- Node.js 18+
- npm or yarn

### Quick Start

```bash
# Clone the repository
git clone https://github.com/rabinsxp/nepali-unicode.git
cd nepali-unicode

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

### Available Scripts

```bash
npm run dev      # Start development server
npm run build    # Build for production
npm run preview  # Preview production build
npm run lint     # Run ESLint
```
